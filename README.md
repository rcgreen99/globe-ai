# GlobeAI

## Description

GlobeAI is a web application that allows you to view a map of the world and click on locations. This will generate a a description of the region using an LLM. To answer the question, it will search the web for information and cite it's sources to allow you to verify claims.

## Tech Stack

### Frontend

- TypeScript
- React
- Next.js
- Tailwind CSS

### Backend

- FastAPI
- Python
- Anthropic/OpenAI/Gemini API
